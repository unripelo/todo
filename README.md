# 📝 To-Do List App

This is my **first project** — a simple and interactive **To-Do List** built using **HTML, CSS, and JavaScript**.  
It allows users to add, delete, and mark tasks as completed in a clean and responsive interface.

---

## 🚀 Features

- ➕ Add new tasks easily  
- ✅ Mark tasks as completed  
- ❌ Delete tasks  
- 💾 Data stored locally using Local Storage (optional improvement)  
- 💻 Responsive and simple design

---

## 🧠 What I Learned

This project helped me understand:
- The **basics of HTML** structure and elements  
- **CSS styling and layout** (flexbox, colors, spacing)  
- **JavaScript DOM manipulation** and event handling  
- How to make a webpage **interactive and functional**

---

## 🛠️ Technologies Used

- **HTML5** — for structure  
- **CSS3** — for styling  
- **JavaScript (ES6)** — for functionality
